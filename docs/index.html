Un comando, cero login, cero cuenta que borrar después. wrangler deploy --temporary levanta una pizarra colaborativa en segundos sobre una cuenta de Cloudflare desechable que dura ~1 hora y desaparece sola — Worker, trazos y todo.

Por qué existe

No toda pizarra necesita vivir para siempre

A veces solo hace falta un espacio para dibujar algo puntual: explicar una idea, bocetar un diagrama, jugar a adivinar. Crear cuenta, configurar y después acordarte de borrarla es fricción que no aporta nada.

⚡

Cero fricción

Sin crear cuenta, sin login, sin tarjeta. Un comando y tenés una pizarra pública funcionando.

🧹

Se limpia sola

Nada que recordar borrar. Pasada la hora, Cloudflare elimina la cuenta temporal y todo lo que contiene.

🔐

Privada por diseño

Modo cerrado con invitaciones de un solo uso si necesitás que dibuje solo gente específica.

Funcionalidades

Lo justo para dibujar en equipo

Construido sobre un único Durable Object por sala: WebSockets en vivo + SQLite para el estado.

✏️

Dibujo en tiempo real

Cada trazo se transmite en vivo mientras lo dibujás, no solo al terminar.

🗂️

Historial persistente

Los últimos 300 trazos se guardan en SQLite del propio Durable Object. Quien entra tarde los ve todos.

📥

Exportar e importar

🔓

Cualquiera con el link, o solo invitados con links de un solo uso generados por el admin.

👑

Cómo funciona

De cero a pizarra en menos de un minuto

Cloná el repo

No hace falta tener cuenta de Cloudflare ni estar logueado.

git clone https://github.com/MauricioPerera/wrangler-ephemeral-whiteboard.git cd wrangler-ephemeral-whiteboard && npm install

Desplegá con --temporary

Wrangler crea una cuenta desechable, despliega el Worker y te da la URL pública.

npx wrangler deploy --temporary

Compartí el link

Mandale la URL de la pizarra a quien quieras. Vive mientras viva la cuenta temporal (~1 hora).

¿Te gustó? Quedátela

Wrangler también te da una claim URL. Abrila y logueate antes de que venza la hora y el Worker pasa a tu cuenta real, para siempre. Si no hacés nada, se borra sola.
